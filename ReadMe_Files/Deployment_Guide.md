## How to Push Updates (Browser Only — No Git)

If you don't have Git installed or prefer using the browser:

### Edit an existing file:
1. Go to https://github.com/ganeshholidays/ganeshholidays.github.io
2. Navigate to the file (e.g., `css/style.css`)
3. Click the **pencil icon** (✏️) to edit
4. Make your changes
5. Click **"Commit changes"** (green button)
6. Site auto-deploys in ~1 minute

### Upload new files (e.g., gallery photos):
1. Go to your repo on GitHub
2. Navigate to the target folder (e.g., `assets/gallery/`)
3. Click **"Add file"** → **"Upload files"**
4. Drag files from your computer into the upload area
5. Type a commit message: `Added new gallery photos`
6. Click **"Commit changes"**

### Create a new file:
1. Go to your repo on GitHub
2. Click **"Add file"** → **"Create new file"**
3. Type the filename with path (e.g., `assets/gallery/newphoto.jpg`)
4. Add content (for text files) or use Upload instead for images
5. Click **"Commit changes"**

## Custom Domain (Future — Optional)

If you buy a domain like `ganeshholidays.in`:

### Step 1: Buy the domain
- Registrars: GoDaddy, Namecheap, BigRock, Google Domains
- Cost: ₹500-800/year for `.in` domain

### Step 2: Configure DNS at your registrar
Add these records:
```
Type: A      Name: @    Value: 185.199.108.153
Type: A      Name: @    Value: 185.199.109.153
Type: A      Name: @    Value: 185.199.110.153
Type: A      Name: @    Value: 185.199.111.153
Type: CNAME  Name: www  Value: ganeshholidays.github.io
```

### Step 3: Add domain in GitHub
1. Go to repo → Settings → Pages
2. Under "Custom domain", enter: `ganeshholidays.in`
3. Click Save
4. Check "Enforce HTTPS"
5. Wait 1-24 hours for DNS propagation

### After setup:
- `https://ganeshholidays.in` → your website
- `https://ganeshholidays.github.io` → still works (redirects to custom domain)
- HTTPS certificate: auto-generated by GitHub (free)

### If you don't renew the domain:
- Only the custom URL stops working
- `https://ganeshholidays.github.io` always works regardless
- Your code, photos, everything on GitHub stays safe (free forever)
- Grace period: ~30-60 days to renew after expiry

## Troubleshooting

| Problem | Solution |
|---------|----------|
| Site not updating after push | Wait 1-2 minutes. Check GitHub Actions tab for build status. |
| Site shows 404 | Make sure `index.html` is in the root of the repo. Check Pages settings. |
| CSS not loading | Check file path is `css/style.css` (case-sensitive on GitHub). |
| Images broken | Check filename matches exactly (case-sensitive). Verify file was pushed. |
| `git push` fails | Run `git pull` first to sync, then try pushing again. |
| Authentication error on push | Use GitHub Personal Access Token or SSH key. Browser popup should appear for auth. |
| Changes visible on GitHub but not on site | Clear browser cache (Ctrl+Shift+R) or wait a few more minutes. |
| Gallery photos not showing | Check `assets/photos.json` has the correct filenames. Check files exist in `assets/gallery/`. |

## Important Notes

- **Never push sensitive data** (passwords, API keys) to a public repository
- **Always test locally first** — open `index.html` in browser before pushing
- **Backup:** Git history IS your backup. Every commit is saved. You can revert to any previous version.
- **The .gitignore file** prevents certain files from being pushed (e.g., system files, backup files)
- **GitHub Pages only serves static files** — HTML, CSS, JS, images. No server-side code (PHP, Node.js, etc.)
